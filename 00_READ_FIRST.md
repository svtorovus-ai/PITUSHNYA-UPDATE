# READ FIRST — PITUSHNYA-UPDATE

Це НЕ source repo PITUSHNYA.

Це public distribution/update endpoint для встановлених Windows PITUSHNYA clients і майбутнього окремого Android Mobile channel.

Source Windows:
`svtorovus-ai/PITUSHNYA-MCC`

Mobile source:
`svtorovus-ai/Pitushnya-Mobile`

Перед зміною manifests/releases прочитай `AGENTS.md` і `docs/PROJECT_GUIDE.md`.

## Критично

Поточні Windows URL contracts вже використовуються встановленими клієнтами.

Stable:
- `version.json`
- tag `pitushnya`
- asset `PITUSHNYA_MCC_Setup.exe`

Beta:
- `beta-version.json`
- tag `pitushnya-beta`
- asset `PITUSHNYA_MCC_Setup.exe`

Backup:
- tag `БЕКаП`
- не чіпати без прямої задачі.

Не перейменовуй ці файли/tags/assets.
